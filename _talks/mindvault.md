## Overview

<div class="academic-callout">
  <strong>🏆 Award: Winner of Best AI/ML Project</strong> at UBHacking 2024 (out of 500+ hackathon participants).
</div>

MindVault is an intelligent browser extension designed to eliminate information fragmentation in personal web navigation. Unlike conventional browser bookmarks that rely on rigid folder hierarchies and uninformative page titles, MindVault leverages natural language processing and semantic embeddings to automatically analyze, summarize, categorize, and index web pages as users browse.

- **Source Code**: [GitHub Repository (rathi-yash/MindVault-AI-Bookmarker)](https://github.com/rathi-yash/MindVault-AI-Bookmarker)

---

## Core Technical Features

1. **Automated Content Distillation**: Extracts key semantic content and metadata from active tabs while filtering out boilerplate and advertising noise.
2. **Contextual Tagging & Categorization**: Computes vector representations of page content to cluster bookmarks into dynamic thematic topics.
3. **Natural Language Semantic Search**: Users query bookmarks using conversational descriptions (e.g., *"that paper discussing diffusion inference speed"*) rather than exact keyword recall.
